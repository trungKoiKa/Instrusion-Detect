# Bản nháp quyển báo cáo

Bản nháp từng chương viết bằng Markdown, xuất ra Word để nhóm sửa tiếp. Mục lục và người viết từng mục: `../muc_luc_bao_cao.md`.

- `chuong_2.md`: chương 2, thiết kế hệ thống.
- `chuong_3.md`: chương 3, triển khai và đánh giá. Mục nào chưa có số liệu thì để trống, ghi rõ còn thiếu gì.
- `tai_lieu_tham_khao.md`: danh sách tài liệu tham khảo dự kiến, khóa trích dẫn dùng trong bài.
- `word/`: file .docx xuất từ các file trên. **Khi đã sửa trên Word thì file Word là bản chính**, không xuất đè lên nữa.

## Quy ước trong bản nháp

- `[cần bổ sung: ...]`: chỗ còn thiếu số liệu, ảnh hoặc thông tin. Trên Word các chỗ này được tô vàng để dễ tìm. Không tự điền số khi chưa đo.
- `[TL:khóa]`: chỗ trích dẫn tài liệu. Khi chốt danh sách tài liệu tham khảo thì đổi thành số `[1]`, `[2]`...
- `![Hình 2.1: ...](hinh/...)`: hình. Chưa có file hình thì trên Word hiện một khung ghi "Chèn hình", kèm mô tả cần vẽ gì.
- Xưng "nhóm". Số thập phân dùng dấu phẩy (0,5), số liệu lấy từ `docs/kich_ban_su_co.md`, `docs/do_dac/`, `docs/tom_tat_trao_doi.md` và code trên `main`.
